개인정보처리방침

trade-shorts는 개인이 자신의 YouTube 채널에 영상을 올리기 위해 쓰는 개인용 도구입니다.

시행일: 2026년 11월 9일

1. 수집하는 정보

이 도구는 타인의 개인정보를 일절 수집하지 않습니다.

회원가입, 로그인, 문의 양식 같은 기능이 없으며, 운영자 본인 외의 이용자가 존재하지 않습니다. 방문자 분석 도구나 광고 추적기도 사용하지 않습니다.

2. Google 사용자 데이터의 이용

이 도구는 Google OAuth 2.0으로 운영자 본인의 Google 계정에 대해서만 아래 권한을 요청합니다.

  • https://www.googleapis.com/auth/youtube.upload — 운영자 본인 소유 채널에 영상을 업로드하는 데에만 사용합니다.
  • https://www.googleapis.com/auth/youtube.readonly — 업로드 대상 채널이 올바른지 확인하기 위해 채널 이름과 채널 ID를 읽는 데에만 사용합니다.

이 권한으로 접근한 데이터는 위에 적은 목적 외에는 쓰지 않습니다. 영상 업로드와 채널 확인 외에 댓글, 시청 기록, 구독자 목록, 수익 정보에는 접근하지 않습니다.

3. 정보의 보관

Google이 발급한 인증 토큰은 운영자 본인의 개인 컴퓨터에만 파일로 저장되며, 외부 서버로 전송되거나 업로드되지 않습니다. 이 도구는 서버를 운영하지 않고, 데이터베이스도 두지 않습니다.

4. 제3자 제공

어떤 데이터도 제3자에게 판매·양도·공유하지 않습니다. 통신은 영상 업로드를 위해 Google의 YouTube Data API와 주고받는 것이 전부입니다.

5. 접근 권한 철회

운영자는 Google 계정 권한 관리 페이지에서 언제든지 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 즉시 무효가 되며, 로컬에 남은 토큰 파일을 삭제하면 모든 접근 수단이 사라집니다.

6. Google API 서비스 사용자 데이터 정책

trade-shorts의 Google API 사용은 Google API 서비스 사용자 데이터 정책을 준수하며, 여기에는 제한적 사용(Limited Use) 요구사항이 포함됩니다.

7. 아동의 개인정보

이 도구는 일반에 제공되지 않으며, 아동을 포함한 누구의 개인정보도 수집하지 않습니다.
